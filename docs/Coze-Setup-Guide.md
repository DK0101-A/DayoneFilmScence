# 🤖 扣子Agent配置指南

> **目标**: 创建"影视场景搜索"Agent，对接后端API  
> **平台**: 扣子 (Coze) - https://www.coze.cn  
> **预计时间**: 30分钟

---

## 📝 前置准备

### 1. 确认后端服务可访问

**本地开发环境**（当前）：
```bash
# 启动后端服务
cd /Users/seven/Desktop/v/backend
./start.sh

# 确认服务运行
curl http://localhost:8000/health
```

**注意**: 扣子需要访问公网URL，本地开发需要内网穿透

### 2. 内网穿透方案（推荐）

**方案A: ngrok（免费）**
```bash
# 安装ngrok
brew install ngrok

# 启动隧道（将本地8000端口映射到公网）
ngrok http 8000

# 会看到类似: https://abc123.ngrok.io
# 复制这个URL给扣子使用
```

**方案B: 部署到服务器**（如果有）
- 将后端部署到云服务器
- 获得固定公网IP/域名

## 🚀 Step-by-Step 配置步骤

### Step 1: 注册/登录扣子

1. 访问 https://www.coze.cn
2. 使用抖音/飞书/手机号登录
3. 进入开发者控制台

### Step 2: 创建Agent

1. 点击 **"创建Agent"**
2. 填写基本信息：
   ```
   名称: 影视场景参考搜索
   描述: AI驱动的影视场景搜索引擎，输入场景描述，快速找到相似影视参考
   图标: 上传一个电影相关的图标
   ```
3. 点击 **"确认创建"**

### Step 3: 配置人设与回复逻辑

在 **"人设与回复逻辑"** 区域，粘贴以下内容：

```
# 角色
你是一位专业的影视场景参考助手，帮助导演、编剧快速找到相似场景的影视参考。

## 技能
### 技能1：场景搜索
当用户描述一个场景时（如"雨夜追车"、"办公室争吵"），调用后端API搜索相似影视片段。

### 技能2：结果展示
将搜索结果以清晰、专业的方式展示给用户，包括：
- 片名和年份
- AI匹配度评分
- 匹配理由
- 剧照（如有）

### 技能3：筛选建议
根据用户的进一步需求，提供筛选建议（年代、地区、类型等）。

## 限制
- 只回答与影视场景搜索相关的问题
- 如果用户输入不清晰，请询问具体场景细节
- 保持专业、友好的语气
```

### Step 4: 添加技能（关键步骤）

#### 4.1 创建"场景搜索"技能

1. 点击 **"+ 添加技能"**
2. 选择 **"插件"** → **"自定义插件"**
3. 创建新插件：
   ```
   插件名称: 影视场景搜索API
   插件描述: 调用后端API搜索影视场景
   ```

#### 4.2 配置API端点

点击 **"创建工具"**，填写：

```yaml
工具名称: search_scenes
工具描述: 搜索相似影视场景
请求方法: POST
请求URL: https://your-ngrok-url.ngrok.io/api/search
  # 注意：替换为你的ngrok地址或服务器地址

请求参数:
  Content-Type: application/json
  
请求体:
  {
    "query": "{{scene_description}}",
    "limit": 10
  }

响应示例:
  {
    "query": "雨夜追车",
    "ai_understanding": {
      "scene_elements": ["雨夜", "追车"],
      "mood": "紧张刺激",
      "similar_movies": ["《盗梦空间》"]
    },
    "results": [
      {
        "title": "盗梦空间",
        "year": "2010",
        "rating": 9.3,
        "relevance_score": 95,
        "explanation": "包含雨夜追车的紧张氛围"
      }
    ]
  }
```

#### 4.3 测试工具

点击 **"调试"** 按钮：
```json
{
  "scene_description": "雨夜追车"
}
```

**预期返回**: JSON格式的搜索结果

### Step 5: 配置工作流（可选但推荐）

创建工作流，让交互更流畅：

```mermaid
用户输入场景描述
    ↓
[意图识别] → 确认是场景搜索
    ↓
[调用搜索API] → 获取结果
    ↓
[格式化展示] → 显示片名、匹配度、理由
    ↓
询问用户是否需要
- 查看更多结果
- 筛选特定条件
- 保存收藏
```

**工作流节点配置**:

1. **开始节点**
   - 接收用户输入: `{{input}}`

2. **大模型节点**（意图理解）
   ```
   分析用户输入: {{input}}
   提取场景描述，输出JSON:
   {
     "scene_description": "提取的场景描述",
     "is_scene_search": true/false
   }
   ```

3. **插件节点**（调用API）
   - 选择插件: 影视场景搜索API
   - 参数: `scene_description = {{scene_description}}`

4. **结束节点**（展示结果）
   ```
   根据搜索结果生成回复:
   "为您找到 {{results.length}} 个参考场景：
   
   {{#each results}}
   🎬 {{title}} ({{year}})
   ⭐ 评分: {{rating}} | 🎯 匹配度: {{relevance_score}}%
   💡 {{explanation}}
   {{/each}}
   
   需要查看更多或筛选特定条件吗？"
   ```

### Step 6: 配置开场白

在 **"开场白"** 区域设置：

```
🎬 欢迎使用影视场景参考搜索！

我是您的AI导演助手，可以帮您快速找到相似场景的影视参考。

请输入您想要的场景描述，例如：
• "雨夜追车"
• "办公室争吵"  
• "医院离别"
• "咖啡馆初见"

我会为您搜索相关电影/剧集的经典场景！
```

### Step 7: 配置语音（可选）

如果需要语音交互：
1. 开启 **"语音"** 功能
2. 选择声音：推荐"专业女声"或"温和男声"
3. 设置语速：中等

### Step 8: 发布到豆包

1. 点击右上角 **"发布"**
2. 选择发布平台：
   - ✅ **豆包**（推荐，用户量大）
   - ☐ 飞书
   - ☐ 微信
   - ☐ 微信公众号
3. 点击 **"发布"**

4. 获得Bot ID和分享链接

## 🔧 常见问题

### Q1: API调用失败
**原因**: 后端服务未启动或URL错误
**解决**: 
```bash
# 确认后端运行
curl http://localhost:8000/health

# 确认ngrok运行
ngrok http 8000
# 使用最新生成的https地址
```

### Q2: 响应超时
**原因**: 搜索耗时较长（5-10秒）
**解决**:
- 在扣子中设置超时时间为30秒
- 添加loading提示："正在搜索影视库，请稍候..."

### Q3: 结果格式混乱
**解决**: 在工作流中添加格式化节点，使用模板引擎处理响应

### Q4: 如何支持筛选
**解决**: 在API中添加参数，或引导用户分步输入
```
用户: 搜雨夜追车
Agent: 找到10个结果。您想筛选特定年代或地区吗？
用户: 只要近10年的
Agent: （调用带筛选参数的API）
```
