# 🎬 Day One Film AI - 完整产品需求文档 (PRD V2.0)

> **项目名称**: Day One Scene AI / D.ONE Film AI  
> **定位**: AI驱动的完整电影制作工作流平台  
> **核心价值**: 剧本 → 场景 → 风格 → 演员 → 视频，全流程AI辅助

---

## 📋 项目概述

### 产品愿景
打造全球首个**导演AI工作流平台**，让每个创作者都能拥有自己的"数字导演助理"，从文字到影像，一站式完成电影级预演。

### 目标用户
- **核心用户**: 导演、编剧、摄影指导
- **扩展用户**: 独立制片人、广告创意、短视频创作者、影视学生
- **B端客户**: 制片公司、广告代理商、流媒体平台

## 🔄 完整工作流（A→E模块）

### Module A: 剧本智能拆解 📄
**功能**: 输入剧本 → AI自动拆分场景和分镜

#### 核心能力
1. **场景识别**
   - 自动识别剧本中的场景转换（INT./EXT. 地点 时间）
   - 提取场景描述、角色对话、动作指示
   - 生成场景列表（带编号）

2. **分镜拆解**
   - 基于场景内容生成建议分镜
   - 每个分镜包含：镜头类型、景别、机位、时长
   - 可视化场景地图（Scene Map）

3. **导演选择界面**
   - 导演可编辑/确认/删除AI建议的分镜
   - 批量操作：全选/取消/重新生成
   - 场景标记：重点场景/普通场景/可删除场景

#### 输出
- 结构化场景列表（JSON）
- 分镜脚本（Storyboard Script）
- 可视化时间线（Timeline）

---

### Module B: 场景参考搜索引擎 🔍
**功能**: 基于场景描述搜索相似影视参考

#### 核心能力
1. **语义搜索**
   - 输入：场景描述（如"雨夜追车"）
   - 搜索：国内外影视片段、剧照
   - 结果：图片 + 视频片段 + 元数据

2. **智能筛选**
   - 年代筛选（80s/90s/近代/现代）
   - 地区筛选（华语/欧美/日韩）
   - 类型筛选（电影/剧集）
   - 风格筛选（悬疑/爱情/动作/喜剧）

3. **结果展示**
   - 剧照/视频截图
   - 片名、集数、时间点
   - 相似度评分
   - 收藏/导出功能

#### 输出
- 参考场景列表（带评分）
- 收藏夹（用户个人库）
- 导出PDF/Excel参考清单

---

### Module C: 场景风格生成器 🎨
**功能**: 基于B模块选择的参考生成AI提示词

#### 核心能力
1. **风格提取**
   - 分析B模块收藏的参考场景
   - 提取视觉风格关键词（光线、色调、构图）
   - 提取情绪关键词（紧张、浪漫、悬疑）

2. **提示词生成**
   - 自动生成Midjourney/Stable Diffusion提示词
   - 生成Sora/Seeddance视频生成提示词
   - 支持中英文双语

3. **风格库管理**
   - 保存导演个人风格偏好
   - 创建风格模板（如"王家卫风格"、"诺兰风格"）
   - 风格相似度匹配

#### 输出
- AI生成提示词（图片+视频）
- 风格参数配置（JSON）
- 可复用的风格模板

---

### Module D: 演员/角色一致性 🎭
**功能**: 选角 + 确保人物形象一致性

#### 核心能力
1. **角色建模**
   - 上传演员照片 → 生成角色数字模型
   - 角色属性：年龄、外貌特征、服装风格
   - 角色关系图（与其他角色的关系）

2. **形象一致性**
   - 跨场景保持角色形象统一
   - 服装/妆容/发型一致性检查
   - 光线条件下的形象适配

3. **选角辅助**
   - 根据角色描述推荐相似演员
   - 演员库管理（照片+资料）
   - 试镜片段生成（AI生成该演员的表演片段）

#### 输出
- 角色数字资产（Character Asset）
- 一致性检查报告
- 演员参考卡（Casting Card）

---

### Module E: AI视频生成 🎬
**功能**: 导入C+D数据，生成最终视频

#### 核心能力
1. **数据导入**
   - 从C模块导入：场景提示词、风格参数
   - 从D模块导入：角色形象、演员数据
   - 从A模块导入：分镜脚本、时间线

2. **视频生成**
   - 集成Sora2/Seeddance API
   - 按分镜批量生成视频片段
   - 支持时长、分辨率、帧率配置

3. **后期处理**
   - 自动拼接分镜（粗剪）
   - 添加转场效果
   - 生成带时间码的预览版本

#### 输出
- 分镜级视频片段
- 粗剪完整版（带时间码）
- 分镜对照表（Shot List）

## 🔧 技术栈

### 后端
- **框架**: FastAPI (Python)
- **AI模型**: 豆包/通义千问 (国内) + Gemini (备用)
- **向量库**: Milvus
- **数据库**: PostgreSQL + Redis
- **消息队列**: Celery + RabbitMQ
- **文件存储**: 阿里云OSS / AWS S3

### 前端
- **扣子Agent**: 豆包生态
- **小程序**: 微信原生 / Taro
- **Web**: React + TypeScript + TailwindCSS

### DevOps
- **容器**: Docker + Kubernetes
- **CI/CD**: GitHub Actions
- **监控**: Prometheus + Grafana
- **日志**: ELK Stack
